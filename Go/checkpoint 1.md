## rune
В Go тип **`rune`** — это просто псевдоним (alias) для типа **`int32`**.
Компьютер не умеет хранить буквы — он хранит только числа. Таблица **ASCII** связывает числа с символами:
'0' = 48
'1' = 49 and so on
из `int` в `rune`
- У тебя есть число `5` (тип `int`).
    
- Если вызвать `z01.PrintRune(5)`, программа напечатает невидимый системный символ (ASCII №5).
    
- Чтобы получить символ `'5'`, нужно к старту отсчета `'0'` (48) прибавить 5:
    
    `'0' + 5` $\rightarrow$ `48 + 5 = 53` (это ASCII-код символа `'5'`).
    
- **Формула:** `rune('0' + digit)`
-**Математика над символом (из `rune` в `int`):**

- У тебя есть символ `r = '5'` (его числовое значение равно 53).
    
- Чтобы превратить его в настоящую цифру `5` для расчетов, нужно вычесть старт отсчета `'0'` (48):
    
    `'5' - '0'` $\rightarrow$ `53 - 48 = 5`.
    
- **Формула:** `int(r - '0')` 
- **Смещение по алфавиту:**

- Какая буква идет через 3 позиции после `'a'`?
    
- `'a' + 3` $\rightarrow$ `'d'` (так как $97 + 3 = 100$).
### 1. Как цифра 5 может быть «символом», а не «числом»?

Представь **бумажную газету**. В ней написано:

> _"В доме 5 этажей."_

В тексте газеты цифра **5** — это просто **рисунок на бумаге** (чернила), такой же рисунок, как буква **"В"** или буква **"а"**.

- Когда ты читаешь текст, ты видишь **картинку** цифры 5.
    
- Компьютер — это математический процессор. Для него число $5$ — это количество чего-то (можно сложить $5 + 5 = 10$). Но если нужно **вывести текст на экран**, монитор не умеет рисовать абстрактные «числа», он умеет зажигать пиксели для **картинки-символа** `'5'`.
    

**В коде Go:**

- `5` (без кавычек) — это **математическое число** (`int`). С ним можно делать $+$, $-$, $*$, $/$.
    
- `'5'` (в одинарных кавычках) — это **символ/рисунок** (`rune`). На самом деле в памяти это число `53` (код в таблице ASCII), которое говорит экрану: _«нарисуй значок 5»_.
    

### 2. Зачем вообще переводить Число в Символ и наоборот? (Практическая польза)

Это не бесполезно, на этом держится вся работа консоли и текстовых файлов.

#### Зачем превращать СИМВОЛ в ЧИСЛО? (Символ $\rightarrow$ Число)

Когда пользователь вводит в консоль текст `"123"`, программа получает **строку из 3 символов**: `'1'`, `'2'`, `'3'`.

Если ты попытаешься сделать `"123" + 5` в Go, программа выдаст ошибку, потому что **нельзя прибавить число к тексту**.

Чтобы посчитать математику, ты должен перевести каждый символ в цифру (как в `Atoi`):

$$\text{Символ } '1' \rightarrow \text{Число } 1$$

$$\text{Символ } '2' \rightarrow \text{Число } 2$$

$$\text{Символ } '3' \rightarrow \text{Число } 3$$

Теперь у тебя есть число `123`, и ты можешь считать формулы.

#### Зачем превращать ЧИСЛО в СИМВОЛ? (Число $\rightarrow$ Символ)

Ты посчитал в программе результат: `res := 5`. Функция вывода `z01.PrintRune()` **принимает только графические символы** (руны). Если ты отдашь ей `z01.PrintRune(5)`, она полезет в ASCII-таблицу и попытается напечатать символ №5 (это невидимая служебная команда, экран останется пустым). Чтобы вывести твою пятерку на экран, ты переводишь число `5` в его текстовую руну `'5'`: `z01.PrintRune(rune('0' + 5))` $\rightarrow$ экран показывает значок **5**.

### 3. Как легко понимать, КОГДА делать перевод?

Запомни простую схему 80/20:

1. **Если ты считаешь математику (сложение, поиск минимального, циклы)** $\rightarrow$ ты работаешь с **`int`** (числами).
    
2. **Если ты читаешь входную строку / аргументы** $\rightarrow$ ты берешь символы **`rune`** и переводишь их в **`int`** через `r - '0'`.
    
3. **Если ты печатаешь результат через `z01.PrintRune`** $\rightarrow$ ты берешь свой **`int`** и переводишь его в **`rune`** через `'0' + n`.

### Наглядный пример из жизни

Запись `[]rune(s)` читается справа налево:

1. **`s`** — наша исходная строка (например, `"cat"`).
    
2. **`rune`** — тип данных «один символ» (буква, цифра или значок).
    
3. **`[]rune`** — это тип данных **«список символов»** (массив из нескольких `rune`).
    
4. **`[]rune(s)`** — это команда **конвертации**: _«Возьми строку `s` и распили её на список отдельных символов-рун»_.
    
Представь слово: `s := "Go"`

1. Когда это просто `string` (`"Go"`), это единый текст.
    
2. Когда мы пишем `runes := []rune(s)`, происходит следующее:
    
    - `runes[0]` становится равным `'G'`
        
    - `runes[1]` становится равным `'o'`
        

Теперь `runes` — это список из двух отдельных элементов: `['G', 'o']`.

### Зачем нам это нужно делать?

Только для двух главных вещей на практических задачах:

1. **Чтобы узнать точное количество букв в слове:**
    
    Функция `len(runes)` считает, сколько символов лежит в этом списке.
    
2. **Чтобы менять буквы местами:**
    
    В обычной строке `s[0] = 'A'` написать **нельзя** (Go выдаст ошибку).
    
    А в списке рун `runes[0] = 'A'` написать **можно**!
пример 
func LastRune(s string) rune {
runes := []rune(s)
return runes[len(runes)-1]
}
func main() {
fmt.Println(string(LastRune("opace")))
}
это берет слово и возвращает самый посл символ

### Чеклист правил по `rune` (Запомни эти 3 формулы)

1. **Строка в список рун:**
    
    - `runes := []rune(s)` — разбирает строку `s` на отдельные символы.
        
    - `len(runes)` — показывает честное количество букв/символов.
        
    - `runes[0]` — первый символ, `runes[len(runes)-1]` — последний символ.
        
2. **Символ в Число (для математики/`Atoi`):**
    
    - `digit := int(r - '0')`
        
    - _Пример:_ `'7' - '0'` $\rightarrow$ $55 - 48 = 7$
        
3. **Число в Символ (для печати через `z01.PrintRune`):**
    
    - `charRune := rune('0' + n)`
        
    - _Пример:_ `'0' + 7` $\rightarrow$ $48 + 7 = 55$ (символ `'7'`)

## ЧЕКЛИСТ КВЕСТ 2 (Вывод, циклы, условия)

#### 1. Алфавиты и цифры

- Итерируемся прямо по рунам: `for r := 'a'; r <= 'z'; r++` или `for r := '0'; r <= '9'; r++`.
    
- Обратный порядок: `for r := 'z'; r >= 'a'; r--`.
    

#### 2. Перебор комбинаций (`PrintComb`, `PrintComb2`)

- Для уникальных сочетаний каждый следующий цикл начинается с `предыдущий + 1`.
    
- Запятая с пробелом `,` печатаются **для всех, кроме последнего элемента**.
    
- В `PrintComb2` печатаем две цифры числа через деление и остаток:
    
    - Первая цифра: `rune('0' + a/10)`
        
    - Вторая цифра: `rune('0' + a%10)`
        

#### 3. Вывод целого числа (`PrintNbr`)

- Выполняется рекурсивно через `/ 10` и `% 10`.
    
- Для отрицательных чисел сначала печатаем `'-'`, а остаток превращаем через `rune('0' - (n % 10))`.
    

## ЧЕКЛИСТ КВЕСТ 3 (Указатели, строки, Atoi, сортировка)

#### 1. Указатели (`PointOne`, `UltimatePointOne`, `Swap`, `DivMod`)

- `*p = 1` — запись значения по указателю.
    
- `***p = 1` — запись через 3 уровня указателей.
    
- `Swap(a, b *int)` — обмен: `*a, *b = *b, *a`.
    
- `DivMod`: `*div = a / b` и `*mod = a % b`.
    

#### 2. Работа со строками (`StrLen`, `StrRev`)

- Длина: `len([]rune(s))`.
    
- Разворот: меняем местами элементы в `runes := []rune(s)` с помощью двух указателей от краев к центру: `runes[i], runes[n-1-i] = runes[n-1-i], runes[i]`.
    

#### 3. Главная задача экзамена: `Atoi` (Перевод строки в число)

- Запомни шаблон проверки на ошибки:
    
    1. Если длина `0` — возвращаем `0`.
        
    2. Проверяем знак в начале: `'-'` (sign = -1) или `'+'` (sign = 1).
        
    3. В цикле: если символ не цифра (`r < '0' || r > '9'`), **сразу возвращаем `0`**.
        
    4. Формула накопления: `res = res*10 + int(r - '0')`.
        
    5. Возвращаем `res * sign`.
        

#### 4. Сортировка массивов (`SortIntegerTable`)

- Пузырьковая сортировка (Bubble Sort) слайса `[]int` через два вложенных цикла: `if table[j] > table[j+1] { table[j], table[j+1] = table[j+1], table[j] }`.
