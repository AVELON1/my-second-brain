### 1. Как вводить длинные команды в терминале без Shift+Enter

Используй символ **обратного слэша (`\`)** в самом конце строки и нажимай обычный **Enter**:

Bash

```
grep -A 5 "L337" vehicles \
  | grep -B 1 -A 4 "Make: Honda" \
  | grep -B 2 -A 3 "Color: Blue"
```

Когда ты ставишь `\` и нажимаешь Enter, терминал понимает, что команда не окончена, выводит символ ожидания `>` и дает продолжить ввод на новой строке.

Если же цель — просто выполнить несколько команд подряд **в одну строчку**, используй разделители:

- `;` — выполнять команды последовательно, независимо от того, завершилась ли первая с ошибкой.
    
- `&&` — выполнять вторую команду **только если** первая завершилась успешно.

### 2. Как отфильтровать блоки с машинами по всем трем параметрам

#### Почему этот путь лучший: 
`awk` умеет менять текстовый разделитель записей. Если указать, что каждая машина — это отдельный блок данных (разделенный двойным переносом строки `\n\n` или строкой `--`), `awk` проверит наличие **всех трех условий сразу** внутри одного блока, независимо от порядка строк.

Bash

```
awk -v RS="--" '/L337/ && /Make: Honda/ && /Color: Blue/' vehicles
```

**Как это работает и почему это лучше всего:**

1. `-v RS="--"` переопределяет `Record Separator` (разделитель записей). `awk` теперь видит файл не как набор отдельный строк, а как блоки данных о каждой машине, разделенные `--`.
    
2. `/L337/ && /Make: Honda/ && /Color: Blue/` — логическое **И** (`&&`). Команда напечатает блок целиком **только если** в нем есть все 3 совпадения.
    
3. Это отрабатывает за 1 проход по файлу, работает мгновенно и не вырезает лишние строки.
    

#### Способ 2: Конвейер из `grep` (Pipes)

Если хочется остаться исключительно в рамках `grep`, можно последовательно сужать выборку с помощью флага `-P` (PCRE, Perl-совместимые регулярные выражения) в режиме работы с многострочным текстом, либо использовать `pcregrep`.

Если установлен `pcregrep`:

Bash

```
pcregrep -M "License Plate L337[\s\S]*?Make: Honda[\s\S]*?Color: Blue" vehicles
```

_Флаг `-M` позволяет искать совпадения через несколько строк._

Если работаешь со стандартным `grep`:

Bash

```
grep -A 5 "L337" vehicles | grep -B 1 -A 4 "Make: Honda" | grep -B 2 -A 3 "Color: Blue"
```

_Минус этого пути:_ приходится вручную высчитывать смещение строк через `-A` (after) и `-B` (before), что хрупко и может сбиться, если структура файла изменится.

#### Способ 3: Временный конвертер блоков в одну строку

Идея в том, чтобы сжать информацию об одной машине в одну длинную строку, отфильтровать простым `grep`, а затем вернуть обратно текстовый вид.

Bash

```
sed 'N;N;N;N;N;s/\n/ /g' vehicles | grep "L337" | grep "Make: Honda" | grep "Color: Blue"
```

### Доказательство и вывод

Для решения задач типа Command-Line Murder Mystery (где дан файл `vehicles` с разделением блоков через `--`), **Способ 1 с `awk` является золотой серединой**:

1. **Скорость и логика:** Не нужно высчитывать количество строк до или после совпадения (`-A 5`, `-B 2`).
    
2. **Точность:** Исключаются ложные срабатывания, когда `Honda` относится к одной машине, а `Color: Blue` — к следующей за ней в файле.
    
3. **Минимум кода:** Команда пишется в одну строку и легко масштабируется (можно добавить `&& /Owner: .../` при необходимости).
    

**Итоговая команда для вставки в терминал:**

Bash

```
awk -v RS="--" '/L337/ && /Make: Honda/ && /Color: Blue/' vehicles
```
